# Project structure

```
Assets/                 3D assets from the asset AI (see Docs/ASSET_PROMPTS.md)
  Units/                rifleman, machine_gunner, sniper, rocket_soldier, medic (.glb)
  Enemy/                grunt, scout, brute, gunner, warlord, boss_colossus (.glb)
  Ingame/               tree_a/b, rock_a/b, building_a/b/c, barrier_a/b, spike_wall, gate_pillar
  UI/                   icons / sprites (later)
Scene/
  Ingame/               Battle (main), GatePair, SpikeWall
  Units/                Soldier
  Enemy/                Enemy, Boss
  UI/                   HUD
Scripts/
  Autoload/             Game (event bus + registries), AudioManager
  Core/                 Models (asset loader + fallback), PlaceholderModels, Mats
  Ingame/               Battle, Army, CameraRig, GatePair, SpikeWall, LevelBuilder
  Effects/              Fx (particles, popups), ProjectilePool (bullets, 1 draw call)
  Units/                Soldier, SoldierDB (stats)
  Enemy/                Enemy, Boss, EnemyDB (stats)
  UI/                   HUD
  Dev/                  SimPilot (headless autopilot, run with: -- --sim)
Sounds/                 generated by Tools/generate_sounds.py
Docs/                   asset prompts, this file
```

Asset lookup: `Models.unit("res://Assets/Units/rifleman", fallback)` tries `.glb`, `.gltf`, `.tscn`.
Missing file = primitive placeholder (PlaceholderModels.gd). Delete a placeholder builder once its asset ships.
